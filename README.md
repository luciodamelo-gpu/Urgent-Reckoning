# Urgent-Reckoning
A rogue mod that adds cards that has custom stats


# Dependencies

* TACZ
* Apothic Attributes

## Build / run

```bash
export JAVA_HOME=/mnt/hdd/tools/jdk-17.0.20.1+1
export PATH=$JAVA_HOME/bin:$PATH
./gradlew build -x test
```

Mod id `cardmod`, Minecraft 1.20.1 / Forge 47.x. `/respec` opens the card picker,
`/card` is OP only command.
